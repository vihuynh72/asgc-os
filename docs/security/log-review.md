# Log Review Checklist

## Weekly
- Review audit events for:
  - Role assignments and term rollover
  - Finance approvals and state transitions
  - ICC attendance edits and club status changes
- Spot check 3-5 random admin actions for correctness.

## Monthly
- Export audit log for the month.
- Verify no unexpected service-role calls.
- Confirm break-glass functions were not used without a ticket.

## Escalation
- If an anomaly is detected, open an incident ticket and freeze further admin changes until reviewed.
