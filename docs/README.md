# Documentation

This directory separates current operating material, historical plans, system specifications, and governing documents.

## Start here

- [`governance`](governance): Constitution and Bylaws source records
- [`specifications`](specifications): product, architecture, data, security, and office-hours design inputs
- [`runbook`](runbook): launch and authentication verification procedures
- [`security`](security): threat model, permission matrix, credential rotation, and log review
- [`ops`](ops): backup, retention, and restore procedures
- [`phase-checklists`](phase-checklists): historical demo and acceptance criteria, not proof of execution
- [`plans`](plans): dated design and implementation plans, retained as historical context
- [`history`](history): consolidated phase progress and handoff history
- [`public-release-checklist.md`](public-release-checklist.md): final approval and verification gate before publication

Specifications, phase criteria, and dated plans describe design intent at the time they were written. Current application code, applied migrations, approved governance records, and verified runtime behavior take precedence when they disagree.
