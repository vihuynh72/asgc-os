# Constitution and Bylaws

This directory keeps ASGC governing documents separate from product specifications and application code.

## Repository copies

- [`asgc-constitution-2026-02-27.docx`](asgc-constitution-2026-02-27.docx), source filename dated February 27, 2026. The cover identifies the Constitution as adopted June 23, 2016.
- [`asgc-bylaws-2026-02-27.docx`](asgc-bylaws-2026-02-27.docx), source updated February 27, 2026.

The visible document content is preserved as received. Their DOCX packages passed structural validation, and neither file contains Word comments or tracked revisions. A Microsoft Word print-layout render of all 13 Constitution pages and all 48 Bylaws pages was reviewed. No clipped text, overlaps, blank pages, or broken glyphs were found. Personal creator, last-modifier, custom-property, and Word revision-session metadata was removed for public distribution without changing document text.

The Bylaws source contains three stale internal page references. On rendered page 7, the desk and office contracts are described as pages 47 and 48, but they render on pages 45 and 46. On rendered page 43, the mascot contract is described as page 35, but it renders on page 44. These references were not silently changed because this repository does not establish authority to amend governing text.

Before external publication, an authorized ASGC or district representative must confirm each document's approval status, effective date, whether it supersedes an earlier version, and how the stale Bylaws references should be corrected or accepted. Do not infer formal approval from the filename alone.
