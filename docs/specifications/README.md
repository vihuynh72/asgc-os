2. [`01_stack_and_architecture.md`](01_stack_and_architecture.md), architecture and phased delivery model
3. [`02_data_model.md`](02_data_model.md), core entities and relationships
4. [`03_security_and_permissions.md`](03_security_and_permissions.md), role and access model
5. [`04_office_hours_spec.md`](04_office_hours_spec.md), office-hours behavior and acceptance criteria

Historical migration comments still refer to these files by their former root-level names. The filenames were retained so those references remain recognizable after the files moved into this directory.
